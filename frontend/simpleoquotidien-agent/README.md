# SimpleÔQuotidien — Espace Agent

Templates HTML/CSS statiques (aucun JS, aucun framework).

## Arborescence
- `index.html` — redirection vers le tableau de bord
- `pages/` — 13 pages de l'espace Agent
- `assets/styles.css` — design system complet

## Pages
1. `dashboard.html` — Tableau de bord
2. `commandes.html` — Liste des commandes
3. `commande-detail.html` — Détail d'une commande
4. `assignation.html` — Assignation d'un prestataire
5. `recherche.html` — Recherche des prestataires
6. `comparaison.html` — Comparaison des prestataires
7. `assignations.html` — Historique des assignations
8. `reassignations.html` — Commandes à réassigner
9. `devis.html` — Validation des devis
10. `notifications.html` — Notifications
11. `prestataire.html` — Profil d'un prestataire
12. `historique-commande.html` — Historique d'une commande
13. `parametres.html` — Paramètres

Ouvrez simplement `index.html` dans votre navigateur.
